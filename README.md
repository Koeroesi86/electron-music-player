Open-Source Lossless Audio Player

### Deving and Building

| Command            | Purpose                              |
| :----------------- | :----------------------------------- |
| `npm run dev`      | Start development server             |
| `npm run build`    | Compile JS `/build`.                 |
| `npm run dist`     | Build for current OS                 |
